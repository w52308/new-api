# derouter.ai 分销指南

> 来源：https://derouter.ai/docs/reseller
> 抓取时间：2026-08-17
> 副标题：从 $200 到第一笔利润 —— 小明的完整分销流程

derouter.ai 上分销很简单：充值主余额，用自己的定价创建客户密钥，发给客户，赚差价。

下面跟着 **小明** 走一遍完整流程 —— 充 $200，第一个客户定价 $100（他成本 $60），40% 利润。

---

## 资金流概览

```
小明 ──► 主账户余额 $200 ──► 客户密钥
                                    │
                      你的成本: $60 │
                      客户售价: $100 │
                      40% 利润率    │
                                    ▼
                           客户看到 apikey.cloud
                              $100 (显示)
                              −$60
                           你的利润: +$40 (40%)
```

## Walkthrough：小明的第一把客户密钥

### Step 1 — 充值 $200

在 [登录](https://derouter.ai/login) 注册，回到 [API](https://derouter.ai/api) 页面，点 **充值**，付 $200（加密货币或银行卡）。

```
┌─────────────────────────────┐
│ 账户余额                    │
│ $200.00                     │
│ 可用: $200.00               │
└─────────────────────────────┘
```

### Step 2 — 和客户谈好价格

小明和 **Acme 公司** 谈好卖 $100 的 API 额度，他自己从 derouter.ai 买的成本 $60。

这两个数字 —— **客户售价** 和 **你的成本** —— 就是下一步要填的全部。没有“利润率”这个字段，系统自动算。

### Step 3 — 创建客户密钥

在 [API](https://derouter.ai/api) 页面点 **创建密钥**，备注名填 `acme-corp-prod`，客户售价和你的成本都填好，预览区会实时更新：

**创建 API 密钥**

| 字段 | 值 |
|------|-----|
| 标签 | `acme-corp-prod` |
| 客户将看到的额度 | $100.00（你的客户在 apikey.cloud 上将看到的金额） |
| 你实际支付 | $60.00（从你的主余额中扣除 · 可用余额: $200.0000） |

**实时预览：**

| 项目 | 值 |
|------|-----|
| 你的余额将扣 | −$60.0000 |
| 客户将看到的额度 | $100.0000 |
| 你的利润 | +$40.0000 (40%) |

点 **创建**，主余额从 $200 变成 $140，列表里多了一把新密钥。

### Step 4 — 把密钥发给客户

复制完整 API key，连同客户 portal 链接一起发给客户：

> Acme 您好，
> 您的 API Key: sk-ant-1234567890abcdef...
> 查看额度请访问: https://apikey.cloud（用您的邮箱 OTP 登录，一次性绑定即可）

客户通过 [apikey.cloud](https://apikey.cloud) 自助查询用量，不需要你在 derouter.ai 上帮他们开账号。

### Step 5 — 客户绑定后看到 $100

Acme 用邮箱 OTP 登录，粘贴密钥，看到 **$100 的额度**，永远看不到你的 $60 成本。

```
您的余额
$100.00 / $100.00
0% 已使用
RPM: 60 · 并发: 5
```

### Step 6 — 查看自己赚了多少

一周后小明打开 [API](https://derouter.ai/api)，Acme 已消费 $34.20，卡片上显示已经赚到 **$13.68**（$34.20 × 40%），而且随着 Acme 继续调 API 实时增长。

密钥卡片示例：

```
acme-corp-prod
sk-ant-1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcd
[复制] [续费 +] [回收预算 −] [编辑 ✎] [删除 ×]

客户剩余额度: $65.8000
已用 $34.2000 / $100.0000

你实际支付 $60.0000
+$13.6800 已入账利润
```

### Step 7 — 客户快用完了，给他续费

一个月后 Acme 快用完了，要加 $50。小明在卡片上点 **[+]**，填 **$50** —— 系统按创建时锁定的 40% 比例自动算出成本 $30，不用心算，也不会意外改价。

**给客户密钥续费**：sk-ant-12345… · acme-corp-prod

| 项目 | 值 |
|------|-----|
| 客户剩余额度 | $5.8000 / $100.0000 |
| 定价比例（创建时锁定） | 40% |
| 追加给客户多少 | $50.00（可用余额: $170.0000） |
| 你的余额将扣 | −$30.0000 |
| 客户新总额度 | $150.0000 |
| 本次利润 | +$20.0000 |

确认后，主余额再扣 $30，客户新总额度变成 $150，已入账利润随 Acme 继续消费持续增长。

## FAQ & 进阶话题

### 我想给团队内部分发，不想加价怎么办？

把“你实际支付”填成跟“客户将看到的额度”一样的数字。系统会自动显示 “无加价（内部分发）”，这把密钥就成了给团队成员的一份额度，不是转售。

### 为什么创建后改不了利润率？

改了会让客户看到的 spent/remaining 数字突然跳变，破坏客户对账单的信任。想重新定价，直接建一把新的客户密钥，让客户换用即可。

### 删除客户密钥剩的钱去哪了？

未消耗的成本部分会立刻退回你的主余额。已经消耗掉的部分是真实 API 调用花掉的，不会退回来。

### 速率限制（RPM / 并发）能改吗？

目前固定 60 RPM / 5 并发，写死的。按 key 自定义限速在路线图里，还没开放。

### 一把客户密钥能给多个客户用吗？

可以。多个客户邮箱可以在 apikey.cloud 绑定同一把客户密钥，共享这个额度。适合小团队或共享服务账号、不想做到人维度追踪的场景。

### 利润率是怎么算的？

`(客户售价 − 你的成本) / 客户售价`

例如：($100 − $60) / $100 = 40%。这是“按客户价计的加价比例”，是分销行业的标准算法。

### 我还想通过拉新赚钱？

可以，两种分销模式互不冲突，很多用户同时做。分享你的推荐链接，就能从被推荐人的消费中拿 5%–30% 阶梯返佣。详见 [推荐返佣文档](https://derouter.ai/docs/referral)。
